## 💡 About The Project

**Hero Apps** is an immersive web application designed to simulate a premium digital marketplace. Unlike standard lists, this project creates a rich user experience allowing users to browse, analyze, and manage applications in a simulated environment.

It leverages **React 19** and **Tailwind CSS v4** to deliver a fluid, responsive interface that feels like a native app store.

### 🌟 Core Features

*   **📱 Immersive Marketplace** — A visually stunning UI inspired by top-tier app stores.
*   **⚡ Simulation Logic** — Experience "Install" and "Uninstall" actions with persistent state via **LocalStorage**.
*   **📊 Data Visualization** — Real-time analytics and rating charts powered by **Recharts**.
*   **🔔 Smart Notifications** — Interactive feedback using **SweetAlert2** (modals) and **React Toastify** (toasts).
*   **🧭 Next-Gen Routing** — Utilizes **React Router 7** for seamless, instant page transitions.
*   **🎨 Modern Design System** — Crafted with **DaisyUI 5** & **Lucide Icons** for a polished aesthetic.

---

## 🏗 Technical Architecture

This project is built on the bleeding edge of the React ecosystem.

*   **Core Framework:** `React 19` + `Vite 7`
*   **Styling Engine:** `Tailwind CSS 4` + `DaisyUI 5`
*   **Routing:** `React Router 7`
*   **State Management:** `React Hooks` + `LocalStorage API`
*   **Icons & Graphics:** `Lucide React`
*   **Visualization:** `Recharts`
*   **Network:** `Axios`

## 🚀 Installation Guide

Follow the steps below to set up the environment locally.

### Prerequisites
*   **Node.js** (v18.x or higher)
*   **NPM** (v9.x or higher)

### 1. Clone the Repository
```bash
git clone https://github.com/your-username/a08-heroapps.git
cd a08-heroapps
```
### 2. Install Dependencies
```bash
npm install
```
### 3.Start Development Server
```bash
npm run dev
```
